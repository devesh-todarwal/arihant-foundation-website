# 📝 Volunteer & Candidate Form — Setup Guide

This is the "join us" form the website will point to. It uses **Google Forms**, which saves
every response into a **Google Sheet** automatically — that's your simple, reliable database.
No server, nothing to maintain.

You can set this up in parallel while filling the questionnaire. Or send me the answers and
I'll guide you click-by-click. Either way, at the end you'll paste me the **form link** and
I'll wire it beautifully into the site.

---

## Recommended fields

Copy these straight into a new Google Form. (⭐ = make it *Required*.)

| # | Question | Type | Required |
|---|----------|------|----------|
| 1 | Full name | Short answer | ⭐ |
| 2 | Email address | Short answer *(Response validation → Email)* | ⭐ |
| 3 | Phone / WhatsApp number | Short answer | ⭐ |
| 4 | City / area you live in | Short answer | ⭐ |
| 5 | I'd like to join as… | Multiple choice: *Volunteer · Intern · Full-time candidate · Partner · Just exploring* | ⭐ |
| 6 | Skills or areas you can help with | Checkboxes: *Teaching · Fundraising · Social media/design · Events · Medical/health · Admin · Fieldwork · Other* | |
| 7 | How much time can you give? | Multiple choice: *A few hours/month · Weekly · Weekends · Full-time · Flexible* | |
| 8 | Why do you want to join us? | Paragraph | ⭐ |
| 9 | Anything else you'd like us to know? | Paragraph | |
| 10 | How did you hear about us? | Short answer | |

*(Tell me if you'd like to add/remove any — e.g. age, occupation, availability dates.)*

## Step-by-step (5 minutes)

1. Go to **forms.google.com** → **Blank form**.
2. Title it something warm, e.g. *"Join [NGO Name] — Volunteer & Candidate Application."*
   Add a one-line description (I'll help you write this once I know the tone).
3. Add each field from the table above. Toggle **Required** on the ⭐ rows.
4. Click the **Responses** tab → the green **Sheets icon** → *Create new spreadsheet*.
   Now every application lands in that sheet automatically. ✅
5. Turn on alerts: in the **Responses** tab → **⋮ menu** → *Get email notifications for new responses*.
   Your mother will get an email each time someone applies.
6. Click **Send** (or the **🔗 link icon**) → copy the shareable link.
   Optionally shorten "Get link." **Paste that link to me** — I'll embed/link it on the site.
